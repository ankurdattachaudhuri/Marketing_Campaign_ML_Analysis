# Marketing Campaign Response Prediction — Group ML Assignment

## Included files
- `Marketing_Campaign_Data.xlsx` — working data extract + data dictionary
- `Marketing_Campaign_Group_Project.ipynb` — executed Jupyter notebook
- `Marketing_Campaign_Group_Project.html` — HTML export of the notebook
- `Marketing_Campaign_Group_Project_Report.docx` — full project report
- `Marketing_Campaign_Prompt_Log.pdf` — AI prompt log and decision annotations
- `Marketing_Campaign_Analysis_Extract.csv` — CSV version of the working extract

## Dataset source
Primary source: Kaggle Customer Personality Analysis
https://www.kaggle.com/datasets/imakash3011/customer-personality-analysis

Public mirror used to create the reproducible extract:
https://github.com/amankharwal/Website-data/blob/master/marketing_campaign.csv

## Important academic note
The executed project uses a 110-row extract from the public dataset so that the analysis can be reproduced in the supplied environment. The original Kaggle dataset contains about 2,240 records. For final faculty submission, replace the extract with the full Kaggle file and rerun the notebook if possible. The modeling code is already structured for the full dataset.
